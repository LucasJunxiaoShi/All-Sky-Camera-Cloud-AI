# All-Sky AI Cloud Classification Project

A project that utilizes the all-sky camera to train artificial intelligence for auto-weather detection. It potentially brings significant benefits for Pomfret School facilities and athletic department.

The goal is to build a large, high-quality labeled dataset that can later be used to train machine learning models for automated sky condition monitoring.

---

# Project Goal

This project aims to classify all-sky camera images into several cloud coverage categories:

- Clear
- Low Cloud
- Medium Cloud
- High Cloud
- Overcast

The long-term goal is to integrate AI cloud detection into observatory automation systems and real-time sky monitoring tools.

---

# Why This Matters

Cloud conditions are critical for:

- Astronomical observations
- Telescope automation
- Weather monitoring
- Observatory scheduling
- Night sky imaging

This project explores how computer vision and machine learning can assist observational astronomy.

---

# How You Can Contribute

We are currently building the training dataset.

Contributors can help by:

- Sorting images into the correct cloud category
- Reviewing mislabeled images
- Expanding nighttime datasets
- Adding metadata information
- Testing the AI model later

No programming experience is required for image classification contributions.
